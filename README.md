# Documentation module

Static Radius prototypes for the documentation module. Import this repo in Vercel as **Other** (no framework, no build).

## Surfaces

| Path | Surface |
| --- | --- |
| `/` | Picker |
| `/client-portal` | Client portal (web) |
| `/radius-client-app.html` | Client app (mobile) |
| `/radius-office-app.html` | Office / agent app |

## Local

Open `index.html` over HTTP (not `file://`) so relative assets load.
